## ✨ Features

- 🔍 **10,862 movies** from the TMDB dataset
- 🤖 **TF-IDF + Cosine Similarity** — accurate content-based recommendations
- ⚖️ **Smart weighting** — Genres ×5 · Keywords ×4 · Director ×3 · Cast ×2 · Overview ×1
- ⚡ **Parallel poster fetching** — 12 threads, ~1-2s load time
- 🖼️ **Zoom-on-hover cards** with gradient overlay showing genre, rating, year & runtime
- 🎬 **Full-screen detail view** — poster left · info right · overview below
- 🎭 **Mood-Based Discovery** — 8 moods mapped to genre filters
- 💾 **Smart caching** — `@st.cache_resource` for the model, `@st.cache_data` per movie
- 🐍 **Python 3.11+ compatible** — no backslash-in-f-string syntax issues

## 🚀 Quick Start

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/cinematch.git
cd cinematch
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Add your TMDB API key

Create `.streamlit/secrets.toml`:

```toml
TMDB_API_KEY = "your_api_key_here"
```

Get a free key at [themoviedb.org/settings/api](https://www.themoviedb.org/settings/api)

### 4. Generate model files (run once)

Open `main.ipynb` in Jupyter and run all cells:

```bash
jupyter notebook main.ipynb
```

This creates `movies_new.pkl` and `similarity_new.pkl` (~2 minutes).

### 5. Launch the app

```bash
streamlit run app.py
```

Open [http://localhost:8501](http://localhost:8501) in your browser.

## 🧠 How It Works

### Tag Construction

Each movie is converted into a weighted string of tokens:

```
tags = (genres × 5) + (keywords × 4) + (director × 3) + (cast × 2) + overview
```

| Field | Weight | Why |
|---|---|---|
| Genres | ×5 | Primary category signal |
| Keywords | ×4 | Most specific — e.g. `nihilism`, `heist`, `dual identity` |
| Director | ×3 | Same director = consistent style and tone |
| Cast | ×2 | Actors often appear in same-genre films |
| Overview | ×1 | Broad signal for fine-grained differentiation |

### TF-IDF Vectorisation

```python
TfidfVectorizer(max_features=12000, stop_words="english", ngram_range=(1,2), min_df=2)
```

TF-IDF down-weights common words (`man`, `life`, `world`) and rewards distinctive terms (`David_Fincher`, `nihilism`, `sandstorm`). This is why the recommendations are accurate — unlike CountVectorizer which treats all words equally.

### Cosine Similarity

A sparse 10,862 × 10,862 similarity matrix is computed once. At query time, the app reads one row, sorts by score, and returns the top matches with valid TMDB posters.

## ☁️ Deploy to Streamlit Community Cloud

1. Push your code to GitHub (see section below)
2. Go to [share.streamlit.io](https://share.streamlit.io) → **New app**
3. Select your repository → set **Main file path** to `app.py`
4. Click **Advanced settings → Secrets** and paste:

```toml
TMDB_API_KEY = "your_api_key_here"
```

5. Click **Deploy**

> On first run, the app auto-generates `movies_new.pkl` and `similarity_new.pkl` (~90 seconds). All subsequent visits load from cache instantly. You do **not** need to upload the pkl files.

## 🐛 Troubleshooting

| Problem | Fix |
|---|---|
| `KeyError: TMDB_API_KEY` | Create `.streamlit/secrets.toml` with your key |
| `FileNotFoundError: movies_new.pkl` | Run all cells in `main.ipynb` first |
| Blank poster cards | Check your TMDB API key is valid |
| Slow first load on cloud | Normal — similarity matrix is being generated (~90s) |
| `ConnectionResetError` | Fixed — app retries 3× with back-off automatically |
